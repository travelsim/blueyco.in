# blueyco.in
Bluey coin tracker - RAM mint prices, eBay sold prices, retailer listings

Legacy static prototype from the old `blueycoin` repo is still available at `/app`.

The live catalogue covers 48 coins across four series. Series 4 contains the
2027 Bluey Cricket $1 coloured uncirculated and coloured silver proof coins.
RAM's launch announcement lists 200,000 and 20,000 mintages and launch prices
of $25.00 and $112.50 AUD respectively:
https://www.ramint.gov.au/about-us/whats-new/bluey-cricket-collectible-coins-celebrating-aussie-tradition
